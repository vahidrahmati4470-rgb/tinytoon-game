# ماجراجویی تینی: هویج طلایی

بازی پلتفرمر فارسی کامل با ۵ مرحله، باس فایت، صدا و کنترل لمسی.

## نحوه بازی
- Enter یا Space برای شروع
- فلش‌ها یا A/D برای حرکت
- Space یا W برای پرش
- P برای توقف

## لینک سایت (بعد از فعال‌سازی GitHub Pages)
https://vahidrahmati4470-rgb.github.io/tinytoon-game/

برای فعال‌سازی:
1. برو به Settings > Pages
2. Source را روی Deploy from a branch بگذار
3. Branch: main و folder: / (root)
4. Save

سپس چند دقیقه صبر کن تا سایت بالا بیاید.
